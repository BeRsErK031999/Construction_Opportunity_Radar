# HTTP API

Внутренний HTTP API Construction Opportunity Radar предоставляет минимальный transport-контур MVP: liveness, реестр источников, персональные возможности, профиль пользователя и обратную связь.

Текущий контракт — `v1`. Пути пока не содержат версию; каждый ответ передаёт `X-Radar-API-Version: 1`. Несовместимое изменение требует нового контракта и отдельного решения о versioning путей.

- [Private API v1](private/v1/README.md)
- [Навигация по контрактам](SUMMARY.md)

API предназначен для loopback-доступа приложений модульного монолита. Публичная публикация до security hardening запрещена.
